# Feature Memory

Return from PTO, understand what changed around your story, and resume your unfinished work.

Feature Memory is a proposed Agent-Native hackathon application for a developer returning after a one-week PTO handover. It compares Jira and Figma snapshots, finds relevant feature-channel decisions, exposes missing context, and produces an editable, evidence-backed resume-work brief. The first workflow uses imported example evidence, follow-up drafts, and attributed recorded replies; live integrations are deferred.
